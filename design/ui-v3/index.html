设计原则（相对现状 v2 的升级点 · 对标 Codex）

去色彩近单色石墨色系；蓝/紫装饰与发光全部移除，主 CTA 用白按钮（亮色主题反转为黑），强调色只留给语义状态。
扁平发丝线半透明 hairline 边框 + 透明底组件；工具行、子代理卡、Todo 条不再套灰盒，悬停才浮现表面。
大留白消息流收窄到 820px、行高 1.7–1.8；空会话 = 幽灵 logo + 大标题在上 1/3 + 大片留白，composer 沉底加宽，上下文 chips 独立成条贴在输入框上方。
层级靠字重活动态 = 浅灰底 + 字重升半级，不再用彩色指示条/彩点；过程信息降为 faint 灰，完成态只留一枚绿点。
