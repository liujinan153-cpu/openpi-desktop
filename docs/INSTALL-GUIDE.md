# 📖 OpenPi Desktop 傻瓜安装指引

> 面向零基础用户的完整安装与上手教程。全程只需鼠标点击，不需要命令行。

---

## 第一步：下载安装包

1. 打开浏览访问项目的 **GitHub Releases 页面**：<https://github.com/liujinan153-cpu/openpi-desktop/releases>
2. 在最新版本（最顶上那个）的 **Assets** 区域里，根据需要下载其中一个：
   - **安装版**：文件名形如 `OpenPi Desktop Setup x.x.x.exe` —— 双击安装、有开始菜单图标，适合大多数人。
   - **便携版**：文件名形如 `OpenPi Desktop x.x.x-portable.zip` —— 解压即用、不写注册表，适合不想安装或放 U 盘里用。
3. 等待下载完成（安装版约 100~200MB，视网络情况几分钟）。

**你会看到什么**：浏览器底部或右上角出现下载进度条，完成后得到一个 `.exe` 文件（安装版）或一个 `.zip` 压缩包（便携版，需右键「全部解压缩」再进解压出的文件夹）。

---

## 第二步：过 SmartScreen 蓝色提示（安装版必看）

1. **双击**下载好的 `Setup .exe`。
2. Windows 可能弹出一个**蓝色警告窗口**，写着：

   > **Windows 已保护你的电脑**
   > Microsoft Defender SmartScreen 阻止了无法识别的应用启动……

3. 不要慌，这是**预期行为**：本项目尚未购买 Windows 商业代码签名证书（个人开源项目，证书不便宜），所以 Windows 不认识它。应用本身没有任何问题。
4. 在蓝色窗口上点击 **「更多信息」** 四个字（在标题正下方）。
5. 窗口会展开，底部多出一个 **「仍要运行」** 按钮 —— 点击它。
6. 接下来按安装向导点「下一步 / 安装」即可。

**你会看到什么**：点「更多信息」后蓝色窗口变成普通安装窗口；安装完成后桌面上出现 OpenPi Desktop 图标（便携版则直接运行解压目录里的 exe，同样可能需要过一次 SmartScreen）。

> ⚠️ 安全提醒：请**只从上面第 1 步的官方 GitHub Releases 页面**下载，不要从网盘、群文件等来路不明的地方拿安装包。

---

## 第三步：首次启动

1. 双击桌面上的 **OpenPi Desktop** 图标。
2. 首次启动可能要等几秒钟（初始化本地引擎）。

**你会看到什么**：出现一个深色的主界面，中间有「今天想做点什么？」欢迎语和两个大按钮（探索并理解代码 / 构建新功能）。底部有输入框。能看到这个界面就说明启动成功了。

---

## 第四步：配置模型（API 密钥）

AI 要能说话，需要一个模型 API 密钥（相当于「话费充值卡」）：

1. 点击界面上的 **⚙ 设置** 按钮，打开「模型与供应商」窗口。
2. 默认停在 **「API 密钥」** 标签页，在下方表单里：
   - 第一格填供应商 ID（如 `zhipu`、`openai`、`anthropic`）；
   - 第二格粘贴你的 **API Key**；
   - 点 **「保存密钥」**。
3. 密钥只保存在你电脑本地的 `~/.pi/agent/auth.json`（权限 0600，仅本人可读），**不会上传到任何服务器**。
4. 如果你用的是公司内网 / 自建服务 / Ollama 本地模型，切到 **「自定义供应商」** 标签页，填 Base URL 和模型列表后保存；本地模型（Ollama / LM Studio / vLLM / llama.cpp）也可以走 **「本地模型」** 标签页一键接入。

**你会看到什么**：保存后密钥列表里出现一行，显示供应商名和打码的密钥（如 `sk-abc…xyz`），旁边有绿色圆点。

---

## 第五步：选择审批档位（重要！）

审批档位决定 AI 可以**自动做多少事**，在输入框附近的选择器里切换：

| 档位 | AI 能做什么 | 适合谁 |
|---|---|---|
| **只读** | 只能看代码 / 搜索 / 回答问题，不能改任何东西 | 新手首选、不熟悉的项目 |
| **自动编辑** | 可以直接改文件，但执行命令 / 操作电脑仍要问你 | 新手推荐，日常写码够用 |
| **全自动** | 改文件、执行命令、操作电脑全部自动，无需确认 | 老手 + 熟悉的项目 |
| **计划模式** | 先只读探索并给出计划，你批准后才执行 | 大改动前的预演 |

> ⚠️ **新手建议**：用 **「只读」** 或 **「自动编辑」**。**不要一上来就开全自动** —— 全自动模式下 AI 会直接动你的文件和系统。首次切到「全自动」时会弹确认框提醒你，需要点「仍要开启」才会生效。

**你会看到什么**：切换档位后，聊天区会出现一行系统提示「🛡 审批模式：XX」。

---

## 第六步：发送第一条消息

1. 先用**低风险的任务**试试水，比如在输入框输入：

   > 帮我看看这个项目结构

   （或直接点欢迎页的「探索并理解代码」按钮）
2. 按回车发送，AI 会开始分析并回复。如果是只读档位，它做的每件事都影响不了你的文件 —— 放心试。
3. 熟悉了之后，再逐步交给它真正的任务。

**你会看到什么**：消息出现在聊天区，AI 开始流式回复；若它要执行需要审批的操作，界面上会弹出批准 / 拒绝的按钮。

> 💡 建议：先在一个**不重要的测试文件夹**里试，跑熟了再用于正式项目。

---

## 第七步：出问题了怎么办？

如果应用报错、卡住或行为异常：

1. 打开 **⚙ 设置 → 关于与更新** 卡片，点 **「📦 导出日志包」**。
2. 选择保存位置，会生成一个 `OpenPi-日志包-日期.zip` 文件（内含运行日志、脱敏后的配置和环境信息，**不含 API 密钥和会话内容**）。
3. 把这个 zip 发给维护者（GitHub Issue 或联系方式），并附上一两句现象描述（做了什么、预期什么、实际发生什么）。

**你会看到什么**：点「导出日志包」后按钮短暂变为打包中，然后提示「✓ 已导出: 文件路径」。

---

## 常见问题

- **SmartScreen 又弹了 / 每次都弹？** 没有代码签名就是这样，每次点「更多信息 → 仍要运行」即可；或右键 exe → 属性 → 勾选「解除锁定」。
- **杀毒软件报毒？** 多为误报（Electron 打包应用常见），可在杀软中添加信任；前提仍是从官方 Releases 下载。
- **启动后一片白 / 黑屏？** 显卡驱动过旧可能导致渲染异常，更新显卡驱动后重试；仍不行请走第七步导出日志反馈。
- **API 报 401 / 余额不足？** 检查第四步的密钥是否填对、供应商账户是否有余额。
